## Project overview
This beginner data-analytics project cleans and analyses 1,000 synthetic telecom customer records using Python, Pandas and NumPy.

## Files
- `2026B02310041_Sparsh_Sharma_Telecom_Churn_Analysis_Executed.ipynb`: completed notebook with outputs
- `06_customer_churn_expanded_1000.csv`: unclean input dataset
- `06_customer_churn_cleaned_1000.csv`: cleaned dataset
- `06_customer_churn_final_analysis_1000.csv`: final dataset with derived analysis columns

## Main work
- Missing-value and duplicate checks
- Median imputation for missing monthly charges
- Overall churn and retention calculation
- Contract, tenure, internet-service and payment-method analysis
- Support-ticket analysis
- NumPy statistics
- IQR outlier detection
- Customer segmentation
- Findings and five retention recommendations
